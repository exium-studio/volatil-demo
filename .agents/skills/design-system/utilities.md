# Exium Utility Components

Located in `@/design-system/components/utilities/ui/`.

---

## 1. ModalPurger (`modal-purger.tsx`)

Utility component that purges orphaned modal URL search parameters on route transitions.

---

## 2. OfflineAlert (`offline-alert.tsx`)

Sticky banner indicating browser network disconnection and reconnect events.

---

## 3. ClickDelegateContainer (`click-delegate-container.tsx`)

Delegates click events from an outer container to an inner interactive target element without breaking accessibility.

---

## 4. Portal (`portal.tsx`)

Chakra portal wrapper for rendering overlays outside the standard DOM hierarchy.
